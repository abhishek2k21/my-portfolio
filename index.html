01.1

PulseGate

Reactive API gateway on Spring WebFlux

Java Spring WebFlux Redis Lua Prometheus Grafana

Problem

Rate limits have to hold across replicas rather than per instance, and the gateway needs to shed load before one slow dependency takes the service down with it.

Built

Atomic Redis Lua scripts implementing token-bucket, sliding-window and fixed-window limiters that stay correct across replicas. An adaptive circuit breaker, a live WebSocket dashboard for gateway state, and Prometheus + Grafana instrumentation. Load-tested with Artillery.

Read case study GitHub

01.2

HandOff

AI agent supervision platform

Java 21 Spring Boot 3 PostgreSQL Flyway React 19 TypeScript Vite

Problem

Once an AI agent acts on real support tickets, you need to see what it is doing, stop it at the right moments, and be able to show afterwards exactly what happened.

Built

A supervision layer for AI agents on support tickets: live monitoring, human approval gates before consequential actions, and an audit trail. Security covers JWT + RBAC, refresh-token rotation with reuse detection, Redis-backed rate limiting and single-use WebSocket tickets. Java 21 and Spring Boot 3 on PostgreSQL with Flyway migrations, React 19 and TypeScript on the front end.

Read case study GitHub
